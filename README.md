# 财务工具箱 Windows 更新

本仓库用于发布财务工具箱的 Windows 安装包、更新索引与版本说明。

[下载最新版本](https://github.com/ZHANGZX-git/finance-toolbox-updates/releases/latest)

## 首次安装与后续升级

1. Windows 64位电脑首次下载安装包；应用已内置 Python，无需另装运行环境。
2. 0.1.3及更早版本需要手动安装一次0.1.4或更新版本。
3. 之后打开“设置 → 应用更新”，检查并下载新版本，完成后点击“重启并更新”。
4. 有排队或正在处理的任务时，先完成任务再安装更新。

默认更新仓库为 `ZHANGZX-git/finance-toolbox-updates`。可在设置中控制是否自动检查；下载和安装由用户操作。

## 本地数据

财务文件处理在本机完成。供应商、存货类别与任务记录保存在本机用户数据目录，升级保留这些资料。更新请求只用于获取程序版本和更新包。

本仓库不包含用户财务原表、处理结果、供应商数据或本地数据库。Mac目前沿用本地安装包升级，未接入本仓库的自动更新。

## 发布文件

每个正式版本包含 Windows `.exe`、对应 `.exe.blockmap` 与 `latest.yml`。这些文件须来自同一次构建，旧版本资产保留用于差分下载。安装包目前尚未配置发行者签名。
